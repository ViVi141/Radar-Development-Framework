# RDF 雷达 — 能力边界与可做事项

本文说明游戏内雷达**现在是什么**、相对现实电磁波雷达**缺什么**、在 Arma / Enforce 约束下**还能做什么**。  
实现细节见 [RADAR_GAME_FRAMEWORK.md](RADAR_GAME_FRAMEWORK.md)；离线原型见 [tools/dem/RADAR_FRAMEWORK.md](../tools/dem/RADAR_FRAMEWORK.md)。

---

## 1. 架构定位（不是什么）

| 误解 | 实际情况 |
|------|----------|
| 离线数字孪生算完再回灌游戏 | **否**。游戏内 Enforce 实时跑检测；`tools/dem/` 是同约定的离线原型/调参，不驱动游戏内检出结果。 |
| 真正的电磁波传播（场求解 / FDTD） | **否**。是功率与检测链路的工程近似，不是波在空间里传。 |
| 训练级雷达信号处理整链 | **否**。没有「波形 → 距离多普勒图 → CFAR → 航迹」完整实时链。 |

一句话：适合做**可玩、带物理门限的传感器玩法**；不适合当电磁仿真器或训练级雷达孪生。

---

## 2. 当前已能做到的效果

### 检测与物理门限

- 扇区 / 可选机械扫描内，发现**载具、炮弹、主动辐射源**
- 距离来自实体几何；通视用 `TraceMove`
- 遮挡时可选 **NLOS 地面反射弱检**（`m_EnableNlosMultipath`），功率衰减后再过 SNR
- 硬件参数 → 雷达方程、多普勒、MTI、处理增益、SNR 门限
- DEM σ⁰ **地面杂波**进入噪声分母（近地/难表面更难发现）
- **噪声压制型 EW**钩子：`RDF_RadarNoiseJammerEffect` → `m_EwStack`

### 显示与测试

- PPI HUD：绿=载具 / 橙=弹丸 / 品红=辐射源 / 青=NLOS 检出
- α-β 实体跟踪
- `RDF_RadarAutoTest`、`RDF_RadarAirborneScanTest` 自动化回归

### 观感上「像雷达」的部分

- 有扫到、漏检、弱检、杂波压目标、干扰抬噪声的感觉
- **不是**地图全亮；远、挡、低 SNR、被压制会丢

## 3. 相对现实电磁波雷达还缺什么

### 传播与回波

- 真多径 / 绕射 / 大气衰减与折射
- 距离门上的杂波谱（不只是 σ⁰ 功率进噪声）
- 目标起伏（Swerling）、闪烁、极化

### 信号与检测

- 脉冲压缩后的真实距离分辨单元
- CFAR / 恒虚警与**匿名 plot**（不依赖实体列表）
- 完整方向图、副瓣、距离/速度模糊
- STAP 等更认真的杂波抑制（现仅简化 MTI）

### 跟踪与系统

- 航迹起始 / 多假设关联（现为实体绑定 + α-β）
- 多雷达组网、IFF、数据链融合
- 搜索 → 截获 → 跟踪模式与资源管理

### 电子战

| 类型 | 状态 |
|------|------|
| 噪声压制 | **已有**（抬接收噪声 → 降 SNR） |
| 欺骗 / DRFM / 拖距拖速 | **未接游戏内** |
| 完整 ECCM | **无** |

### 引擎与联机现实

- 候选目前偏 `GetActiveEntities`，易漏休眠 / 远距目标（宜改球查询）
- 雷达检测结果默认**本地**，无服务器权威同步

## 4. 在现有约束下「能做到」的增强

### 游戏内（推荐）

1. **`QueryEntitiesBySphere`（或 AABB）补全候选** — 减少漏检  
2. **噪声 / 欺骗 EW 组件化** — 载具挂干扰机；假目标点、短时拖距  
3. **简化 CFAR / 距离–方位匿名 blip** — PPI 更像真雷达点迹  
4. 搜索 / 跟踪模式、锁定层对接武器（见 [VEHICLE_RADAR_LOCK_GUIDE.md](VEHICLE_RADAR_LOCK_GUIDE.md)）  
5. 联机：服务器权威同步检测结果  

### 离线（Python + DEM）

- 更认真的传播、杂波谱、CFAR 原型  
- 标定表（功率因子、σ⁰、干扰耦合）再喂回游戏参数  

### 不宜作为游戏内实时主路径

- FDTD / 全场电磁波  
- 训练级信号处理整链每帧跑满  

---

## 5. 建议优先级（只选三条时）

1. 球查询候选  
2. EW 压制组件化 + 简单欺骗  
3. 匿名 CFAR blip  

目标产品形态：**可信的军武传感器玩法**（发现 / 丢失 / 压制 / 欺骗 / 锁定），而不是真实雷达仿真器。
