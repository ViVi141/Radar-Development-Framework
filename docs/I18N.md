# Documentation languages / 文档语言

RDF docs are **bilingual (English + 中文)** so international mod authors and Chinese contributors can share one repo.

## Convention / 约定

| Kind / 类型 | Primary / 主文 | Companion / 对照 |
|-------------|----------------|------------------|
| Public contracts (`RADAR_API`, `RADAR_GAME_FRAMEWORK`, offline `RADAR_FRAMEWORK`) | English | `## 中文` at bottom |
| Contributor guides that started in Chinese (`DEM`, `DEVELOPMENT`, `CAPABILITIES`, `VEHICLE_*`, `TODO`, …) | 中文 | `## English` at bottom |
| `README.md` | English first, then 中文 | Same file |
| `API.md` | 中文 first (LiDAR detail), then `## English` | Keep both in sync when APIs change |
| `CHANGELOG.md` | 中文 entries (history) | New entries should include an English bullet line; full EN mirror is not required for old history |

Jump links: every bilingual doc should start with:

```markdown
> **Languages / 语言**: [English](#english) · [中文](#中文)
```

(Adjust the anchor to match the companion heading used in that file.)

## Editing rules / 编辑规则

1. Prefer updating **both** languages in the same PR when behavior or APIs change.
2. Code identifiers, paths, class/method names stay in English in both languages.
3. If you can only update one language, update the **primary** column above and leave a `<!-- TODO(i18n): sync -->` near the changed section.
4. Do not duplicate huge code trees twice when they are language-neutral — share one fenced block between sections when practical.
